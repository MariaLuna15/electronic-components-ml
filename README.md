# Electronic Components ML 🔍

Modelo de Machine Learning para reconocer componentes electrónicos a partir de imágenes usando Transfer Learning con EfficientNetB0.

## Componentes detectados
- Resistencia
- Capacitor
- LED
- Transistor
- Diodo

## Tecnologías
- Python 3.13
- TensorFlow 2.21
- OpenCV
- Gradio
- JupyterLab

## Precisión
- Train accuracy: 85%
- Val accuracy: 70%
- Test accuracy: 65%
